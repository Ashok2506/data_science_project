# Hotel Booking Prediction

This project focuses on predicting hotel booking outcomes using real-world data. The goal was to analyze, visualize, and model the data to understand booking patterns and predict potential outcomes using machine learning techniques.

## 📊 Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA) and Visualizations
- Applied Machine Learning models to predict bookings
- Model evaluation using accuracy metrics

## 🛠 Technologies Used

- **Python**
  - Pandas
  - Matplotlib
  - Scikit-learn
- **Machine Learning Models**
  - Linear Regression
  - K-Nearest Neighbors (KNN)
  - Decision Tree
  - And others for comparison
